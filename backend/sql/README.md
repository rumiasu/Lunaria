# 独立 MySQL 目标

目标 MySQL 8.0.16+；独立临时 MySQL 8.4.8 / 8.4.13 的真实引擎验证已完成，见 [迁移与差异](mysql/README.md) 和 [云端接棒](../../docs/云端后端接棒.md)。H2 兼容检查与真实 MySQL 引擎检查分别记录，不混同。

全新空 schema 可选择完整 `schema.mysql.sql`，或依序执行 V001–V004，不应重复执行。V004 只新增店长联系资料表，保留旧顾客、本金、卡、预约与流水。版本脚本校验和在 `mysql/migrations/SHA256SUMS`；CI 实际核对文件摘要。没有自动迁移工具、正式应用版本记录或生产迁移管线，MySQL DDL 可能隐式提交。

应用启动仍仅允许回环 H2 demo/test；真实引擎测试直接装配服务与显式合成数据，使用本次新建的随机 schema，结束清理。不得把 demo 指向已有业务库，演示 seed 不可导入生产。

正式 MySQL 运行仍需 Lunaria 专用身份、初始化与迁移版本记录、备份和正式认证独立验收。没有创建持久账号或生产部署，没有复用其他项目的库、账号、AppID、配置或凭据。
