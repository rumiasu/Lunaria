## 有限范围

在线订单只表示**本金充值**，不直接售卡。顾客金额经服务端校验为 1–100000000 整数分后冻结为订单；AppID、商户、付款 openid 从受信渠道上下文与已有绑定取得，不接受浏览器传入。确认支付后在原余额中入本金，再沿既有余额购卡接口消费，不重复计履约或等级。

V006 新增 payment_orders、payment_receipts、channel_refunds、payment_attempts、payment_reconciliation 五张表。业务表共 20 张；没有支付平台、任务队列、员工/多店或营销模块。旧 V001–V005 未改，旧资产与预留保留。

## 订单与回调

先持久化预支付/退款发送意图和防重记录，再在数据库事务外调用渠道，避免网络等待占资金锁。STARTED 意图在崩溃后仍存在；同一操作键只返回该意图，不重发。未知结果为 PAYMENT_UNKNOWN / UNKNOWN，返回 202；显式查单可以恢复可信结果。不同键也不能绕过未知状态重复发送退款。

PaymentGateway 为认证渠道接口，默认 bean 永远关闭，配置一个普通 enable 标志不会生成假渠道。WechatSdkGateway 是显式构造的官方 SDK 桥接，复用现有 JsapiService / NotificationParser，补支付查单、RefundService 申请/查询和退款通知；没有凭据构造器、自动联网或假成功回退。测试替代通道只在测试源码中，以 ISOLATED_FAKE_CHANNEL 标明。

公开通知只有 `/api/payments/wechat/notify` 与 `/api/payments/wechat/refund-notify` 两条精确路径免会话/CSRF，其他资金修改仍需身份、CSRF 和操作键。SDK NotificationParser 先验签解密，再核对服务端订单、商户、应用、付款人、金额、币种与交易结果。订单及 provider_transaction_id 各自唯一；RECHARGE、receipt、余额、状态和审计同一事务。只有事务提交后才返回 204；数据库失败不确认，重试不会重复入账。无渠道配置时通知返回 503，不假确认。

官方 0.2.17 的退款模型没有 mchid 字段；退款商户上下文来自显式配置的认证 SDK/parser。应用仍核对原订单、商户上下文、原支付交易号、退款请求号、原总额、退款金额、币种和唯一 provider_refund_id。原始回调、session_key、签名、密钥及 SDK 调试内容不保存到业务表或审计。

预支付只保存 prepay_id，不是支付成功凭据，也不发卡/增加余额。当前没有生成真实小程序调起签名，前端/真机与真实商户联调继续暂停；不能把预支付票据或内部测试 PAID 当作真实渠道验收。

## 渠道退款与对账

退款必须关联已入账充值订单和 receipt，累计未取消金额不能超过原支付金额，也不能超过当前可用余额。创建时关联现有 BALANCE 退款申请，店长批准后沿既有逻辑预留本金；向原渠道发送不再扣余额。SUCCESS 结果只消费该预留，追加 BALANCE_REFUND_CHANNEL_SETTLED 信息流水，关联原预留和原交易，不记新充值/消费。

| 状态/入口 | 行为 |
|---|---|
| REQUESTED → READY | 店长审核并预留；拒绝不预留 |
| SUBMITTING / PROCESSING / UNKNOWN | 保留本金，不重发、不自动恢复；查单/通知确定结果 |
| SUCCESS | 唯一渠道退款结果/结算流水，重复查询或通知不再扣余额 |
| FAILED（渠道 CLOSED） | 仍保留预留，店长明确解除后才恢复余额 |
| 尚未发送的 READY/REQUESTED | 可明确取消，恢复原预留；不记新充值 |
| 人工对账说明 | 只追加凭据和说明，不能把订单改 PAID 或退款改 SUCCESS |
| 人工确认未退款 | 仅未知/发送中状态，须原金额、外部查账凭据与说明，标为 MANUAL_NO_REFUND；不改余额、不称渠道验证 |
| MANUAL_NO_REFUND 后明确解除 | 恢复原预留，保留人工来源与审计 |
| 取消后矛盾的成功结果 | CONFLICT_REVIEW，保留证据，拒绝成功确认，不强行自动改账 |

普通手工退款入口不能修改渠道管理的预留，避免两条路径重复恢复余额。争议说明仍可保存，未决争议阻止发送/解除；发送后已验证的结果保留真实财务状态及争议标志。真实渠道结果与人工说法矛盾时不伪造结清。所有资金状态修改都要求本店配置行存在并取得事务锁。

## 剩余接入边界

本轮应用账务闭环完成，真实支付通道仍未接通。WechatSdkGateway 需要外部显式装配本项目商户 SDK 客户端和 NotificationParser，并提供真实商户/证书/APIv3 材料、回调 HTTPS/域名；当前没有读取、生成或设置这些凭据。真实小程序调起签名/前端接线、商户沙箱/真实联调和生产运行配置尚未验收，生产 profile 仍关闭。订阅授权额度/发送状态不是本轮支付范围，通知保持关闭。不因内部测试完成宣称真实充值、支付或退款上线。
