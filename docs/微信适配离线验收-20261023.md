# 微信适配离线验收（2026-10-23）

本轮在 `publish/backend-first-release`、基于远端 `303bbdd` 继续。前端、小程序视觉、候选设计和原本地 main 未修改。余额、购卡、预约、核销和退款业务算法未改；不增加员工、多店或营销模块。

## 已交付

- code 交换：固定 HTTPS、超时、错误净化、不回退演示身份；不落库 code/session_key/secret。
- 身份绑定：店长核对后将已验证身份关联已有顾客；事务、单店锁、防重、审计；拒绝覆盖或合并资产。只授予对应顾客 CUSTOMER 会话并更新 session ID。
- 订阅客户端：可信授权检查、内存 token 缓存、绑定收件人/模板/字段映射；拒绝失败假成功和自动重试。未开放发送 HTTP 操作。
- 官方微信支付 SDK 0.2.17 适配：JSAPI 请求映射、官方回调解析器调用、回调时效及商户/应用/订单/付款人/状态/整数分金额核对。没有连接商户、支付回调开放、资金入账或实际退款。
- V003 身份表与完整 MySQL 建库路径一致，保留既有本金和来源流水。API、来源与第三方说明、外部契约及唯一待定清单同步更新。

覆盖 32 项唯一测试，0 失败、0 错误、0 跳过。先执行 31 项通过；对齐绑定防重键并补关联保护后，仅重跑绑定 7 项通过，其中 6 项重叠。未重复业务全套。最终 `bootJar` 成功，开发产物为 `backend/build/libs/lunaria-dev.jar`，不提交构建产物。

```powershell
cd backend
.\gradlew.bat --no-daemon test --tests cn.lunaria.integration.WechatClientsContractTest --tests cn.lunaria.integration.WechatPaymentAdapterTest --tests cn.lunaria.WechatIdentityBindingTest --tests cn.lunaria.ExternalIntegrationBoundaryTest --tests cn.lunaria.MysqlMigrationCompatibilityTest --write-locks --write-verification-metadata sha256

```

最终绑定测试 XML 仅在本机忽略目录，公开计数在 PUBLICATION.json。mock SDK 不证明真实密码学联调；H2 不证明 MySQL；本轮没有微信编译、真机或前端视觉验收。

## 外部前置条件

MySQL 需要已有隔离开发实例地址/端口、空 Lunaria 专用 schema、专用认证和迁移/测试权限，通过未提交配置提供。本机未找到 Docker/Podman，未连接宿主 MySQL、取用其他项目账号或新建账号。应用 MySQL profile 仍须在隔离库实测后建设，不能改演示地址直接生产运行。

真实身份需要独立 AppID/主体、安全配置 AppSecret、真实店长认证与顾客核对方式、HTTPS 和实际 code 联调。订阅需正式模板、可信授权存储/额度和发送状态。支付需合法商户与应用关系、既有密钥/验签材料、HTTPS 回调、权威在线订单、幂等落账和对账。并非只填密钥即可上线；本轮不创建凭据/外部账户，不执行真实支付、退款或通知。

接口与状态见 [外部服务契约](外部服务契约与禁用边界.md)，业务待定规则只维护 [首版规则与待定项](首版规则与待定项.md)。
