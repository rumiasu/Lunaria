# 首版后端交付 · 2026-10-23

当前优先级为后端完成，前端、三版 HTML 设计与小程序视觉均暂停。本轮没有访问或修改 design 目录，也没有改动小程序或共享样式。

## 本轮三项必要修复

1. **冲正后的分精度守恒**：原实现按已用次序估算履约值，乱序冲正再核销可能制造 1 分。现在按原 SERVICE / REVERSAL 流水恢复金额，只把尚未履约实付值分摊到剩余次数。反复冲正和使用后总额仍等于原购卡价。
2. **已售卡时长权益保护**：时段查询和预约增加可选本人 cardId，保留已售项目名称/时长；核销拒绝短于卡快照的预约。项目调短、套餐改价改次数均不重算旧卡权益。售卡规则快照记录配置版本和默认/显式等级价来源。
3. **退款记录与结算分离**：普通退卡依旧直接试算、人工审核登记，不加步骤。争议处理记录仅 note 必填，可只保存“已联系店长/原因核对中”；原因、拟议金额、利息、证据和顾客确认标志均可选。不强制多轮顾客确认，不建立复杂证据流程。拟议少退或算法有争议也可留存，只有结算执行受到原因和金额规则保护。审计追加，不覆盖原原因/试算；利息默认 0，不是首版使用门槛。

辅助收敛：`MembershipPolicy` 明确默认 TRACK_ONLY，只保存履约参考值而不自动升降级；充值、购卡、核销、退款本金与可选利息有独立摘要。正式累计认定不被硬编码为承诺。审核决定、配置启停等字段必须明确传值，缺字段不会默认为拒绝或暂停。新接口及例子见 [API 清单](API清单.md)。
