# 页面清单 · 原生微信小程序功能线框

| 端 | 路由 | 信息与操作 |
|---|---|---|
| 顾客 | pages/home/index | 护理项目、时长、默认/单套餐专属价、演示身份、余额购卡 |
| 顾客 | pages/booking/index | 未来 30 天日期、可约时段、申请、等待店长确认说明 |
| 顾客 | pages/appointments/index | 本人预约状态、取消不扣次 |
| 顾客 | pages/cards/index | 独立卡包、余次、状态、实付 |
| 顾客 | pages/card-detail/index | 售卡快照、核销来源、单张退卡试算/申请/处理记录 |
| 顾客 | pages/wallet/index | 本金与独立流水、等级演示说明、储值退款入口 |
| 店长 | pages/today/index | 当日待办数、后续待确认、确认/取消/调整、服务完成后核销 |
| 店长 | pages/customers/index | 姓名/编号搜索、到店次数、常用项目、余次、人工待联系 |
| 店长 | pages/customer-detail/index | 卡与预约、来源流水、本金充值登记、核销冲正 |
| 店长 | pages/packages/index | 项目/时长/合理单次价、套餐次数/价/单套餐等级价/暂停销售 |
| 店长 | pages/refunds/index | 原因、证据、试算与规则快照、审核依据、争议保持待处理 |
| 店长 | pages/settings/index | 营业、休息、暂停、容量、演示等级门槛；已有预约保留清单 |

所有页面有加载和异常状态；列表有空状态。触控按钮最小 92rpx，正文 30rpx，次要信息 24–27rpx；对比优先，后续品牌设计不可牺牲可读性。金额输入严格到分，提交期间防重复点击，网络未知结果保留同一操作编号重试。

全局样式源为 `miniapp-shared/tokens.wxss`，运行 `node scripts/sync-miniapps.mjs` 同步两端。当前没有定稿艺术素材。页面样式是功能线框；HTML 渲染适配器若用于布局检查，不等于微信开发者工具或真机验收。
